
# House Party API v2 – User Endpoints

Return to the main [API v2 README](../README.md) or the [project README](../../../../README.md).

This document provides an overview of the user-related endpoints available in the House Party v2 API. These endpoints handle authentication, session management, and user state.


## Available Endpoints

| Endpoint         | Description                                 |
|------------------|---------------------------------------------|
| [hasParty](hasParty.md)   | Check if a user currently has a party      |
| [login](login.md)         | Authenticate and start a user session      |
| [logout](logout.md)       | End a user session                        |
| [sessioninfo (SSE)](sse/README.md) | Real-time session info via Server-Sent Events |

---

For more details on each endpoint, see the linked documentation above.

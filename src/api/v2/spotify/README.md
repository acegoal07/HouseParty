## Overview
These endpoints handle interaction between the House Party application and the Spotify API. This is done to keep sensitive information away from the client side and keep the users data secure.

## Endpoints Summary
| Endpoint                      | Method | Description                                 |
|-------------------------------|--------|---------------------------------------------|
| `/addSongToQueue.php`         | GET    | Adds a song to the user's Spotify queue     |
| `/searchForSong.php`          | GET    | Search for a song on Spotify                |
